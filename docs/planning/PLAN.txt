3. THE AGENTS
-----------------------------------------------------------------
1. Recall Watcher  (addressing: anyone)
   - On new CDSCO alert or new medicine added: matches family's batches (KinCare matcher)
   - Posts alert in room, tags caregivers + @Pharmacy agent
2. Scan Agent
   - Dadi sends a strip/bill photo -> KinCare OCR -> batch -> check -> Hindi reply
   - Adds medicine to the family list (room knowledge)
3. Pharmacy Agent
   - On recall handoff: finds same salt from a clean maker + price saving
   - Asks the HUMAN pharmacist to approve -> on "approve" logs a Decision + creates Task
4. Dose Buddy
   - Hindi reminders; missed dose -> tells caregiver in room (with consent)

All agents: never diagnose, never tell anyone to stop a medicine; always route to a human.
